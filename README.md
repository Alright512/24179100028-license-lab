# 课程资料整理工具 (Course Material Organizer)

## 项目介绍
本项目是一个计划用 Python 编写的命令行小工具，旨在帮助用户按课程和日期自动整理学习资料。目标用户是需要管理大量课程文件的学生或自学者。**当前项目处于设计阶段（开发中），暂无可用代码。**

## 安装或获取方式
**当前为设计阶段，暂无安装包。**
后续开发完成后，计划提供基于 `pip` 的安装方式。目前您可以阅读本仓库的设计文档或关注后续更新计划。

## 使用说明
由于项目尚未实现，当前暂无运行命令。预期在开发完成后，用户可通过输入指定的课程名称与日期参数，将对应文件自动分类归档。
